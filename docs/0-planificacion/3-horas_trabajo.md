# Registro de Horas de Trabajo

En el presente documento se busca documentar cada actividad ha realizar dentro de cada fase del proyecto. Colocando claramente el tiempo estimado y el tiempo real que tomó hacer cada una de las actividades.

Para las tres primeras etapas y las fases de Implementación y Evaluación, las actividades se harán de forma lineal; sin embargo, la fase de desarrrollo y validación se realizarán, como ya se había detallado, mediante una metodología **SCRUM**, por lo que el detalle de cada Sprint y las horas empleadas se documentará dentro de esa fase.

Durante el desarrollo del proyecto, es posible realizar actividades no previstas desde un inicio. En ese caso, esas posibles actividades emergentes, serán añadidas al registro presente, colocando el tiempo que tomó realizarlas.
